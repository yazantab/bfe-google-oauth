# Privacy Policy

## Personal Use

This Google OAuth 2.0 client configuration is intended exclusively for personal use with Banners File Explorer (BFE).

It is not offered as a public service to other users.

## Google Drive Data

The OAuth configuration allows the account owner to authorize BFE to access Google Drive through Google's authentication system.

Depending on the permissions granted, BFE may read, create, modify, and delete files in the authorized Google Drive account.

## Data Storage and Processing

This GitHub Pages website does not request or collect Google account credentials, OAuth tokens, or Google Drive files.

Google Drive data accessed through BFE is handled by the BFE application and its underlying integrations. This page does not independently process or store that data.

## Data Sharing

The operator of this personal OAuth configuration does not independently collect or sell Google user data through this website.

## Revoking Access

The Google account owner can revoke the application's access at any time through their Google Account security settings.

## Third-Party Software

Banners File Explorer is independently developed software. Its own data handling practices are outside the control of this personal OAuth configuration.
