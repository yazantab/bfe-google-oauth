# Personal Google Drive OAuth Client for Banners File Explorer

This page describes a personal Google OAuth 2.0 configuration used to connect **Banners File Explorer (BFE)** to Google Drive.

## Purpose

Banners File Explorer is a third-party Android file manager that supports access to Google Drive.

This OAuth client is configured independently for private, personal use. It allows the account owner to authorize BFE to access their Google Drive files using Google's OAuth 2.0 authentication system.

The OAuth configuration is not an official product or service provided by the developers of Banners File Explorer.

## Google Drive Access

The OAuth client is intended to authorize access to the user's own Google Drive account. Depending on the permissions requested by BFE, authorized operations may include listing, reading, uploading, modifying, and deleting files.

Authentication and authorization are handled by Google. The OAuth client configuration does not itself store Google passwords.
